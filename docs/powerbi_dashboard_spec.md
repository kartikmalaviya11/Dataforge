# Power BI Dashboard Specification

This document outlines the intended layout and configuration of the manual Power BI dashboard that consumes the outputs generated by the Analytics Readiness & Data Quality Analyzer.

## Output Files Summary
The following deterministic CSV files are generated into `output/` for ingestion into Power BI:
- `dataset_profile.csv`: High-level row/column counts (Metadata).
- `column_metadata.csv`: Detailed type detection and null percentages (Metadata/Summary).
- `quality_issues.csv`: The granular list of every flagged issue (Fact table).
- `quality_summary.csv`: Aggregated counts of issues (Summary).
- `readiness_score.csv`: The overall grade, status, and dimension penalties (Summary).
- `kpi_recommendations.csv`: Feasible business metrics (Recommendation).
- `dax_measures.csv`: Exact DAX code matching the KPIs (Recommendation).

## PAGE 1 — Overview
**Purpose**: Executive summary of data readiness.
- **Visual 1**: **Readiness Score & Grade** (Card/Gauge mapped to `overall_score` and `grade` from `readiness_score.csv`).
- **Visual 2**: **Total Records & Total Columns** (Cards mapped to `dataset_profile.csv`).
- **Visual 3**: **Total Issues & Missing Values** (Cards mapped to `quality_summary.csv`).
- **Visual 4**: **Dimension Scores Breakdown** (Bar chart showing Validity, Completeness, etc., from `readiness_score.csv`).

## PAGE 2 — Data Types
**Purpose**: Review the physical and semantic footprint of the dataset.
- **Visual 1**: **Column Metadata Table** (Table visual mapping `column_metadata.csv`: `column_name`, `storage_type`, `semantic_type`, `confidence`, `status`).
- **Visual 2**: **Null Percentage by Column** (Bar chart mapping `column_name` vs `null_percentage`).

## PAGE 3 — Issue Explorer
**Purpose**: Drill down into specific rows and problems.
- **Slicers**: `issue_type`, `severity`, `column`.
- **Visual 1**: **Issue Details Table** (Table visual mapping `quality_issues.csv`: `issue_type`, `severity`, `column`, `row_index`, `message`, `recommendation`).
- **Visual 2**: **Issues by Type** (Donut chart).

## PAGE 4 — Quality Analysis
**Purpose**: Understand rule compliance and uniqueness.
- **Visual 1**: **Quality Summary Metrics** (Cards for `missing_value_count`, `duplicate_count`, `type_issue_count`, `rule_violation_count` from `quality_summary.csv`).
- **Visual 2**: **Issues by Severity** (Bar chart mapping derived counts from `quality_summary.csv`).

## PAGE 5 — KPI Recommendations
**Purpose**: Present business metric feasibility.
- **Slicers**: `status`, `category`.
- **Visual 1**: **KPI Availability Table** (Table mapping `kpi_recommendations.csv`: `kpi_name`, `priority`, `status`, `available_columns`, `missing_requirements`).
- **Visual 2**: **DAX Measure Code** (Table mapping `dax_measures.csv`: `measure_name`, `dax_expression`, `warnings`).
